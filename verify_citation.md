| **Central Contribution**         | Provides one of the earliest rigorous statistical formulations of **Gravity Model calibration**. Hyman formulates calibration as an optimization problem that maximizes the agreement between observed and predicted trip distributions and derives the iterative procedure that later became known as the **Hyman calibration algorithm**.                                                                                                      |                                                                                                                                                                                                                                                                                                   |
| **Main Contributions**           | • Formulates calibration using Bayesian hypothesis comparison and likelihood evidence.<br>• Shows that model calibration is equivalent to maximizing an evidence (log-likelihood) criterion.<br>• Derives calibration conditions for exponential, power-law, Tanner, and generalized exponential deterrence functions.<br>• Proposes an efficient iterative numerical algorithm for estimating balancing factors and distance-decay parameters.  |                                                                                                                                                                                                                                                                                                   |
| **Strongly Supports**            | • Distance-decay parameters **cannot be assumed** and must be estimated from observed travel data.<br>• Calibration should maximize statistical agreement between model predictions and observations.<br>• Different deterrence functions (exponential, power, Tanner) require different calibration constraints.<br>• The observed average travel cost (or transformed travel cost) provides the calibration target.                            |                                                                                                                                                                                                                                                                                                   |
| **Partially Supports**           | • Gravity Models are probabilistic statistical models.<br>• Bayesian reasoning provides a natural framework for comparing competing trip-distribution hypotheses.<br>• Maximum evidence (equivalent to maximizing the objective defined in the paper) identifies the best-fitting model under the assumed probabilistic formulation.                                                                                                             |                                                                                                                                                                                                                                                                                                   |
| **Does NOT Explicitly Support**  | • Behaviour–Structure Separation.<br>• Behaviour identification from aggregate travel-distance distributions (TLD).<br>• Privacy-preserving mobility inference.<br>• Information Hierarchy of mobility observations.<br>• Cross-city transferability.<br>• Deep learning or AI-based mobility prediction.                                                                                                                                        |                                                                                                                                                                                                                                                                                                   |
| **Core Assumptions**             | • An observed OD survey is available.<br>• Trips are independently sampled from an underlying trip-distribution.<br>• The trip-distribution follows a Gravity-type formulation (p_{ij}=a_i b_j f(\mu,c_{ij})).<br>• Calibration seeks parameter values that maximize agreement with observed OD flows.                                                                                                                                           |                                                                                                                                                                                                                                                                                                   |
| **Methodology**                  | Begins with Bayesian hypothesis testing, derives a multinomial likelihood for observed OD counts, defines an evidence objective (E(H                                                                                                                                                                                                                                                                                                             | DX)=\sum t_{ij}\log p_{ij}), formulates calibration as constrained optimization, and develops an iterative algorithm to estimate balancing factors and the distance-decay parameter. The paper presents explicit derivations for exponential, power, Tanner, and generalized exponential models.  |
| **Data Requirement**             | Requires **full Origin–Destination survey observations**, including trip counts between origin–destination pairs and generalized travel costs. Calibration explicitly uses observed OD flows as the reference data.                                                                                                                                                                                                                              |                                                                                                                                                                                                                                                                                                   |
| **Limitations**                  | The framework assumes access to detailed OD survey data and independent sampling. The proposed algorithm calibrates parameters from observed trip matrices rather than recovering them from aggregated statistics. The paper focuses on statistical fitting rather than behavioural interpretation of the calibrated parameters.                                                                                                                 |                                                                                                                                                                                                                                                                                                   |
